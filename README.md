# 📅 Booking System | نظام إدارة الحجوزات

منصة إلكترونية متكاملة الميزات لحجز المواعيد والخدمات المختلفة مثل (العيادات، الصالونات، والدورات التدريبية). تهدف المنصة إلى تنظيم عمليات الحجز وتسهيل إدارة المواعيد بين المستخدمين والإدارة.

---

## ✨ المميزات الرئيسية (Features)

- 👤 **تسجيل المستخدمين:** إمكانية إنشاء حسابات جديدة وتسجيل الدخول بسهولة.
- 📅 **عرض جدول المواعيد:** استعراض المواعيد المتاحة بشكل واضح وتفاعلي.
- 🛠️ **لوحة تحكم المدير (Admin Dashboard):** لوحة تحكم كاملة لإدارة الحجوزات والمواعيد والخدمات.
- 📧 **إشعارات البريد الإلكتروني:** إرسال إشعارات تلقائية عبر البريد الإلكتروني فور تأكيد الحجز.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** 
  - HTML5 / CSS3 / JavaScript
  - **AJAX** (لتحديث وتحميل البيانات ديناميكياً بدون الحاجة لإعادة تحميل الصفحة)
- **Backend:** 
  - PHP (أو إطار العمل Laravel)
- **Database:** 
  - MySQL (لتخزين وإدارة بيانات المستخدمين والحجوزات بأمان)
